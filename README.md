## About

This is my personal portfolio website created as part of the CS344 Web Engineering course. It showcases my background, skills, hobbies, a photo gallery, and contact information.

## Project Structure

```
portfolio/
├── index.html          # Home page (About Me)
├── hobbies.html        # Hobbies and interests
├── skills.html         # Programming and language skills
├── gallery.html        # Image gallery (6 photos)
├── contact.html        # Contact details and message form
├── css/
│   └── style.css       # External stylesheet for all pages
├── images/
│   ├── Passport-Size-Pic.jpg
│   ├── MyPic.jpg
│   ├── Hobby.jpg
│   ├── Pic1.jpeg
│   ├── Pic2.jpeg
│   └── Pic3.jpeg
└── README.md           # This file
```

## Technologies Used

- **HTML5** for page structure and content
- **CSS3** (external stylesheet) for styling and layout
- **CSS Float & Clear** for arranging content and gallery images
- **Git** for version control

## Features

- Multi-page portfolio with consistent navigation across all pages
- External CSS file (`css/style.css`) shared across all pages
- Horizontal navigation menu styled with CSS
- Float-based layouts for text and image arrangements
- Image gallery with 6 photos arranged using float and clear
- Contact form with a clean, structured design
- Organized folder structure (css/, images/)

## How to View

Open `index.html` in any modern web browser (Chrome, Firefox, Edge).
